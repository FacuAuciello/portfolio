# Portfolio - Facundo Auciello

Portfolio personal desarrollado para mostrar proyectos, tecnologías y soluciones de software orientadas a negocios, profesionales e instituciones.

## Objetivo

El objetivo del proyecto es presentar de forma clara y sencilla diferentes sistemas y aplicaciones web desarrolladas con Java y tecnologías relacionadas.

La idea es que potenciales clientes puedan conocer ejemplos de soluciones como:

- Sistemas de gestión interna
- Gestión de productos y stock
- Sistemas de turnos y reservas
- Plataformas web
- Aplicaciones a medida

## Tecnologías

### Backend
- Java 17
- Spring Boot
- Spring Web
- Lombok
- Maven

### Frontend
El frontend se desarrollará más adelante con:

- React
- TypeScript
- Tailwind CSS
